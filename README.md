# 🫀 Heart Disease Prediction using Decision Trees and Random Forests

## 📌 Objective

This project aims to explore tree-based machine learning models (Decision Trees and Random Forests) using the **Heart Disease Dataset**. We perform classification, evaluate model performance, visualize decision trees, and interpret feature importance.

---

## 📊 Dataset

- **Source:** [Heart Disease Dataset - Kaggle](https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset)
- **Features:** 13
- **Target:** 0 (No Disease), 1 (Disease)

---

## 🛠️ Tools & Libraries

- Python
- Scikit-learn
- Pandas, NumPy
- Matplotlib, Seaborn
- Graphviz (for tree visualization)

---

## 🔍 Models Implemented

1. **Decision Tree Classifier**
   - Trained on raw data
   - Visualized using `plot_tree`
   - Tuned with `max_depth` to reduce overfitting

2. **Random Forest Classifier**
   - Ensemble of 100 trees
   - Compared against single decision tree
   - Feature importance visualized
